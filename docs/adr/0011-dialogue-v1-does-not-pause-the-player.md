# Dialogue doesn't pause the Player; no Host→Engine command channel exists yet

Showing Dialogue naturally suggests freezing the Player while it's up, but that needs the Engine to accept a live command from the Host — a channel that doesn't exist today. Every Host→Engine input so far is the one-shot, declarative `WorldConfig` passed at construction; keyboard handling lives entirely inside the Engine's private `MapScene`, with no hook for the Host to disable it. We're deliberately not building that channel yet: v1 Dialogue renders as a non-blocking Host-side overlay, and the Player can still walk underneath it. This is an accepted rough edge, not an oversight — imperative Host→Engine control (pause/resume, forced movement) is reserved for whenever a CG/cutscene feature, which genuinely needs to take control from the Player, is actually designed.
